# Восстановление R6 с локальным адаптером ScopedKB

[Первый опыт](R6_synthetic_restart_2026-11-04.md) использовал временный файл. Здесь вторым хранилищем служит отдельный локальный Git-репозиторий с искусственным набором v2. Вызов идёт через рабочий [адаптер ScopedKB](https://github.com/dilukhin/scopedkb/blob/e48b8f1e4db3940dafa6ac529c3e1319155f956b/docs/V2_REVIEW_GIT_RU.md). Тест готовит новую копию на каждый запуск. Ссылка предложений и `main` изначально указывают на один коммит.

Перед эффектом ACP сохраняет отпечаток намерения, в котором связаны цель, ожидаемый Git SHA и контрольная сумма кандидата. Первый процесс вызывает адаптер. ScopedKB проверяет допуск, v2 и ожидаемую редакцию, записывает предложение `pending` и обновляет выделенную ссылку. Затем первый процесс завершается до подтверждения в SQLite. Второй контроллер открывает ту же SQLite, отзывает прежнюю попытку и запускает независимое чтение адаптера по исходному идентификатору. Он подтверждает контрольную сумму и единственный дочерний коммит. Ссылка `main` остаётся на исходной редакции. Второе чтение подтверждает те же байты и SHA. Поколение попытки остаётся равным 1.

## Воспроизведение

Из рабочего дерева ACP задайте абсолютные пути к проверенной копии ScopedKB и Python 3.11 или новее. Код адаптера и схемы должны соответствовать коммиту `e48b8f1e4db3940dafa6ac529c3e1319155f956b`. Интеграционный тест запускается с явно выбранной локальной копией. На Linux связка прошла полный набор тестов Go и проверку гонок. Штатные проверки ACP и ScopedKB выполняются отдельно.

```bash
ACP_REVIEW_SCOPEDKB_ROOT=/absolute/path/to/scopedkb \
ACP_REVIEW_PYTHON=/absolute/path/to/python \
go test -count=1 -timeout=2m -v ./internal/reviewproof -run '^TestGitAdapterAcrossProcesses$'
```

Для теста нужен локальный Git. Фикстура создаётся во временном каталоге. Этот результат проверяет границу записи и восстановления на искусственных данных. Рабочее назначение допуска, очередь разбора, долговременное хранение снимка и путь принятия предложения остаются отдельной работой R6.
