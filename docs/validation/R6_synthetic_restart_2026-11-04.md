# Проверка R6 после завершения процесса записи

Проба воспроизводит сценарий A11 из [описания R6](../r6_review_mapping_ru.md#9-искусственные-сценарии-для-реализации). Используются настоящая SQLite ACP и отдельная папка с искусственным набором ScopedKB. Два JSON-снимка прошли внутреннюю проверку v2 на [коммите ScopedKB](https://github.com/dilukhin/scopedkb/commit/2477e917b0bf064100eaf4a42fde386a99a7f510). В исходном снимке два контрольных наблюдения. В следующем снимке к ним добавлены кандидат рекомендации, доказательство и две связи с основаниями.

Первый процесс фиксирует в SQLite операцию, попытку, резервирование и отпечаток намерения в одной транзакции. Отпечаток связывает версию намерения, цель, ожидаемую редакцию и байты результата. После успешной транзакции процесс сверяет исходный снимок и создаёт отдельный файл по устойчивому ключу. Он синхронизирует и закрывает файл и завершает процесс до подтверждения результата в ACP.

Второй процесс открывает SQLite после завершения первого. Он сверяет сохранённое намерение, отзывает старую попытку и читает исходный снимок и результат по прежнему ключу. Совпадение позволяет в одной транзакции записать наблюдение и подтвердить операцию. После этого задача получает `completed`. Неопределённость оставляет состояние `unknown_outcome`. Восстановление не вызывает запись в папку знаний.

| Случай | Что проверено |
| --- | --- |
| Результат записан, ответ потерян | Независимое чтение подтверждает операцию, поколение попытки остаётся 1 |
| Запись отсутствует | Исход неизвестен, новый результат не появляется |
| Запись с тем же ключом отличается | Исход неизвестен, существующие байты сохраняются |
| Исходная редакция изменилась | Совпавшего результата недостаточно для подтверждения |
| Транзакция намерения откатилась | Операция отсутствует, внешнего эффекта нет |

После повторного чтения завершённая операция сохраняет свою редакцию. У прежней попытки больше нет полномочий. Тест сверяет число файлов и байты результата до и после восстановления.

```bash
go test -count=1 -v ./internal/reviewproof
```

Эта проверка относится к контролируемому завершению процесса после синхронизации файла. Второе хранилище представлено тестовым каталогом. Срок хранения ограничен запуском теста. Файлы и контрольные суммы этого опыта не задают постоянный формат намерения. Для R6 остаётся согласовать и проверить исполняемый адаптер ScopedKB с чтением фактической редакции и правилами полномочий на запись.
